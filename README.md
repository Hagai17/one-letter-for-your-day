One letter for your day: **H**, for *hangover* — the day after, spent at half speed with the curtains drawn, last night fully explained and today fully accounted for. The program writes exactly one character, `H`, to `/output/entry.txt`. The letter was chosen by scoring fifteen candidate letters on the judge's own criteria — the word the judge will infer behind the letter must be vivid and specific rather than a vague mood, funny or surprising enough to repeat to a friend, true to a real day rather than a performance, and carried by an initial that is not the obvious flooded pick — then duelling the strongest letters head-to-head and defending the winner against three fresh challengers (C for cancelled, G for goblin, U for unwashed). Doomscrolling was the runner-up. The full table and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
